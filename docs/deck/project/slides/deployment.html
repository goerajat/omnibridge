A VPC with private trading and persistence subnets and a public monitoring subnet.

Security groups per flow: venue ports from clients, admin from monitoring, Aeron between trading and persistence.

IAM roles for S3 artifacts and CloudWatch; hosts install from S3 at boot in a fixed service order.

Solid arrows: order flow and journal replication; dashed: scraping and admin. infrastructure/terraform and scripts/deploy; one pipeline builds, uploads, deploys, restarts and validates

This is the reference deployment the latency numbers come from. Two trading hosts face each other in a placement group, a third host holds the remote journal, and a public host carries monitoring and acts as the SSH bastion. The whole stack is code: one pipeline builds, uploads, deploys and validates, and the latency skill provisions, measures and destroys it. Service start order is enforced: store, MCP server, simulator, initiator, OmniView, monitoring.
