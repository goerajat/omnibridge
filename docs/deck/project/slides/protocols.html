Shared core. One event loop, ring buffer, persistence layer, session service and admin API serve every protocol; a new one adds its codec and state machine.

Many sessions, one port. Routed by CompID pair, OUCH user or SBE session id.

A simulator for all of them, with an order book and symbol-pattern fill rules.

Modules under protocols/: fix, ouch, sbe (ilink3, optiq, pillar); sample applications for each under apps/; FIX tested against QuickFIX/J

FIX is the broadest, with all the common versions and the full session recovery story. OUCH comes in both versions in use today. The three binary protocols share an SBE base. The point of the table is the third column: the session layer is the engine's job in every case, and the application sees orders and executions. A protocol module adds its codec, its state machine and its listener callbacks; everything underneath is shared.
