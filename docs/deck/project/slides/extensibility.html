Proof

The three binary protocols went in this way: iLink 3, Optiq and Pillar share one SBE engine and message base, with one small module per venue. Every session, whatever its protocol, is the same managed session to the admin API, OmniView and the alerts.

docs/PROTOCOL_ARCHITECTURE.md is written as the template for a new protocol: module layout, checklist, metrics and test script conventions

This is the slide for a buyer whose venue list will grow. A protocol is a module: its message layouts, its session rules and a small engine class. The loop, the transports, the journal, the remote store, the admin surface, monitoring, configuration and the test harness are all shared and all unchanged. The three binary protocols are the evidence: they went in on a common SBE base, and operations sees them exactly as it sees a FIX session.
