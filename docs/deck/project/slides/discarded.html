A buyer should know what did not work and why. Several of these are the first things a reviewer would suggest, such as kernel busy polling or turning interrupt moderation off, and both measured zero because the engine already spins. Two were rejected on principle rather than numbers: moving the journal write off the critical path, and a second journal format for a microsecond.
