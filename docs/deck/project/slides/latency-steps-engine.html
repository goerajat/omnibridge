The first six changes are all on the cheapest instance type. The pattern is the same each time: a stage timestamp or a profile pointed at one cost, one change removed it, one run confirmed it. The two largest single wins were spinning with pinning on each side, which removed the wake-up path, and the garbage-free event loop, which removed a GC pause every 0.85 seconds.
